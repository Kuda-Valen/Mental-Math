# Mental Maths

A Python-based mental maths application that helps users practice their arithmetic skills through interactive quizzes.

## Features

- Practice the four basic mathematical operations:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Presents users with a series of randomly generated questions.
- Tracks the user's answers and the time taken to complete the quiz.
- Displays a summary of the user's performance at the end.
- Includes an interactive menu that runs in a continuous loop, allowing users to play multiple rounds or choose different options.

## How It Works

1. Launch the program.
2. Choose an option from the interactive menu.
3. Answer the generated maths questions.
4. View your score, correct answers, and completion time.
5. Return to the menu to play again or exit.
